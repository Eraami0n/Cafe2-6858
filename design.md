# Cafe Park Avenue — карта сайту

Інтерактивна карта сайту + UX-аудит для кав'ярні-кондитерської «Cafe Park Avenue» (м. Монастирище).
Один вебзастосунок (Vite + React 19 + Tailwind 4), 4 режими: Карта, Аудит, Сценарії, Мобільна навігація.
Артефакт аналітичний, не продакшн-сайт — без БД, дані лежать у типізованих TS-модулях `src/web/data/`.

## Typography

- Display: **Prata** (serif, 400) — заголовки H1–H3, логотипні підписи. Відповідає серифу з бренд-макета.
- Body: **Plus Jakarta Sans** (400/500/600/700) — весь інтерфейс, вказаний у самому макеті бренду.
- Обидва шрифти self-hosted у `public/fonts/` (cyrillic + latin), підключені через `@font-face`.
- Ієрархія через розмір і вагу; line-height 1.55–1.7 для тексту, 1.15–1.25 для заголовків.

## Layout & Style

- Тепла органічна база: кремовий фон, зерниста текстура (`.grain`), м'які тіні замість рамок.
- Асиметрична сітка: дерево карти 62% / панель деталей 38% на десктопі; на мобільному — стовпчик.
- Картки зі злегка нерівними радіусами, хайрлайни `hairline`, бейджі-чіпи для пріоритету й типу сторінки.
- Motion: один staggered reveal при зміні режиму (`.reveal`), без розсипу мікроанімацій.
- Антипатерни, яких свідомо уникаємо: PDF-меню, hero-каруселі, важкий parallax, стокові фото.

## Pages

- **Карта** (`pages/index.tsx`) — клікабельне дерево сторінок + панель деталей обраної сторінки; перемикач «Запропонована → Вдосконалена».
- **Аудит** (`pages/audit.tsx`) — 5 категорій знахідок (зайві, відсутні, навігація, дублі, глибина кліків) + таблиця кліків до/після.
- **Сценарії** (`pages/flows.tsx`) — 3 user flows ланцюжками екранів із реакціями системи та станами помилок.
- **Мобільна навігація** (`pages/mobile.tsx`) — макет телефону: sticky bottom bar, drawer, поведінка хаба.

## Key User Flows

1. **Express Pickup**: Головна → Меню (sticky) → модалка товару (модифікатори) → slide-in кошик → Checkout → `/order/:id`.
2. **Custom Cake**: Головна (hero CTA) → `/orders/cakes` (галерея + Lead Time) → `/orders/cakes/build` (4 кроки) → завдаток 30% → `/order/:id`.
3. **Reservation**: Головна → `/reservation` → форма (дата, слот, гості) → `/reservation/:id`.

## Architecture

- Frontend-only: дані карти, аудиту та флоу — типізовані модулі в `src/web/data/`, компоненти в `src/web/components/`, сторінки в `src/web/pages/`, роутинг через wouter у `app.tsx`.
- Без API-роутів і БД: артефакт не має користувацьких даних.
